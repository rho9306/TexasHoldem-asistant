# 德扑助手 v2.0 - 项目完成总结

## 项目概述
德州扑克实时辅助工具，使用蒙特卡洛模拟计算胜率和EV值，提供下注决策建议。

## 已完成功能

### 核心算法模块 ✅
- **Card类** - 扑克牌表示和转换
- **Deck类** - 牌堆管理和洗牌
- **HandEvaluator类** - 手牌强度评估
- **Calculator类** - 蒙特卡洛模拟和EV计算

### 用户界面 ✅
- **ConsoleUI类** - Windows控制台TUI界面
- **InputHandler类** - 键盘输入处理（模拟ESP32按键）
- 分页显示设计（3页）
- 完整的用户交互流程

### 核心功能 ✅
1. **手牌输入** - 支持格式如"As Kh"
2. **公共牌输入** - 支持最多5张公共牌
3. **底池信息** - 底池大小、跟注金额、对手数量
4. **胜率计算** - 蒙特卡洛模拟（500-5000次，自适应）
5. **EV计算** - 跟注EV和加注EV
6. **决策建议** - 强烈跟注/跟注/弃牌等决策等级
7. **加注策略** - 价值加注、保护加注推荐

## 使用方法

### 编译
```bash
cd poker_assist
cmake .
cmake --build .
```

### 运行
```bash
./poker_assist.exe
```

### 输入格式
- 手牌：点数+花色（如"As Kh"、"2h 5d"）
- 底池：数字
- 跟注：数字

### 快捷键
- `C` - 清空输入/下一手
- `Q` - 退出程序
- `H` - 显示帮助

## 技术规格

- 语言：C++17
- 构建系统：CMake + Ninja
- 编译器：GCC 15.2.0 (MinGW64)
- 平台：Windows 10/11
